SiPus - Sistem Peminjaman Perpustakaan Mini
Kelompok 12 - Kelas E

File:
- sipus.h       : deklarasi struct dan prototype fungsi
- buku.cpp      : implementasi F1 (kelola buku)
- anggota.cpp   : implementasi F2 (kelola anggota)
- main.cpp      : menu utama dan input program

Cara compile (C++17):
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp buku.cpp anggota.cpp -o sipus

Cara menjalankan:
./sipus

Catatan:
Ini adalah versi awal untuk memulai Milestone 1 dan sebagian Milestone 2.
Uji program, pahami setiap fungsi, dan sesuaikan bersama anggota kelompok sebelum dikumpulkan.
